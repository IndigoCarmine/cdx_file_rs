# Test Outputs

This directory contains exported SVG and PNG files generated from the sample CDX files in `sample_cdx/`.

## Files

### Standard Conversions (1024x768, 2x scale for PNG)

All sample CDX files have been converted to both SVG and PNG formats:

- **Analysis** - Analysis diagram
  - `Analysis.svg` (5.7 KB)
  - `Analysis.png` (105 KB)

- **Reaction** - Chemical reaction diagram
  - `Reaction.svg` (10 KB)
  - `Reaction.png` (98 KB)

- **Reaction.out** - Reaction output diagram
  - `Reaction.out.svg` (10 KB)
  - `Reaction.out.png` (98 KB)

- **ReactionAnalysis** - Complex reaction analysis
  - `ReactionAnalysis.svg` (15 KB)
  - `ReactionAnalysis.png` (99 KB)

- **benzene** - Benzene molecule structure
  - `benzene.svg` (1.7 KB)
  - `benzene.png` (102 KB)

- **yellow_colored** - Colored molecule structure
  - `yellow_colored.svg` (1.6 KB)
  - `yellow_colored.png` (102 KB)

### Variant Exports (Different Sizes)

Additional benzene exports with different dimensions:

- `benzene_small.svg` - 512x384 pixels
- `benzene_large.svg` - 2048x1536 pixels
- `benzene_hires.png` - High resolution (4x scale)

## Generation

These files are generated by the test suite in `tests/sample_conversion_test.rs`.

To regenerate these files:

```bash
cargo test --test sample_conversion_test -- --nocapture
```

## Usage

These files demonstrate the SVG and PNG export capabilities of the `cdx-file-rs` library using the `AbstractPainter` backend system.
