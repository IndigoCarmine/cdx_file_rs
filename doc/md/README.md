# CDX Specification - Markdown Version

This directory contains the CDX (ChemDraw Exchange) file format specification converted from HTML to Markdown for improved readability by AI agents and developers.

## Source

All files were automatically converted from the original HTML specifications located in `../html/` using the `convert_html_to_md.py` script.

## Contents

- **Root Files**: Main specification documents including index, general introduction, data types, objects, and properties
- **properties/**: Detailed documentation for all CDX properties (263 files)
- **DataType/**: Documentation for CDX data types (16 files)

## Key Files

- [index.md](index.md) - Main documentation index
- [General.md](General.md) - General introduction and examples
- [DataTypes.md](DataTypes.md) - Data type specifications
- [AllCDXObjects.md](AllCDXObjects.md) - Complete list of CDX objects
- [TableOfProperties.md](TableOfProperties.md) - Complete properties table

## Conversion Notes

The conversion script handles:
- HTML tables → Markdown tables
- Links (internal documentation references)
- Text formatting (bold, italic, code)
- Lists (ordered and unordered)
- Removal of Wayback Machine artifacts and scripts

339 Markdown files generated from the original HTML specification.
