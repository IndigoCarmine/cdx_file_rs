## Atom_LinkCountHigh Property

| CDXML Name: | LinkCountHigh |
| --- | --- |
| CDX Constant Name: | kCDXProp_Atom_LinkCountHigh |
| CDX Constant Value: | 0x043E |
| Data Size: | [INT16](/web/20190327001711/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Node](/web/20190327001711/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Node.md) |
| First written/read in: | ChemDraw 7.0 |
| Required? | No |

**Description:**

High end of repeat count for link nodes.

This property is meaningful only for nodes with a [kCDXProp_Node_Type](Node_Type.md) of type LinkNode.

**If this property is absent:**

The LinkCountHigh is assumed to be 1.
