## Magnification Property

| CDXML Name: | Magnification |
| --- | --- |
| CDX Constant Name: | kCDXProp_Magnification |
| CDX Constant Value: | 0x080E |
| Data Size: | [INT16](/web/20160912170038/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Document](/web/20160912170038/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Document.md) |
| First written/read in: | ChemDraw 4.0 |
| Required? | No |

**Description:**

The view magnification factor

The value stored by this property is 10 * the current magnification value, in percent, so 1500 = 150%.

**If this property is absent:**

The document is displayed at 100% magnification.
