CDX Format Specification: CrossReference_Document Property
## CrossReference_Document Property

| CDXML Name: | CrossReferenceDocument |
| --- | --- |
| CDX Constant Name: | kCDXProp_CrossReference_Document |
| CDX Constant Value: | 0x0F01 |
| Data Size: | [CDXString](/web/20160911225929/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXString.md) |
| Property of objects: | [kCDXObj_CrossReference](/web/20160911225929/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/CrossReference.md) |
| First written/read in: | ChemDraw 7.0 |
| Required? | No |

**Description:**  

An external document containing the Sequence object being referenced.

This property is provided for future compatibility and is not currently used in any case by ChemDraw.

**If this property is absent:**  

This is the empty string.
