## Atom_RestrictRxnChange Property

| CDXML Name: | RxnChange |
| --- | --- |
| CDX Constant Name: | kCDXProp_Atom_RestrictRxnChange |
| CDX Constant Value: | 0x0427 |
| Data Size: | [CDXBooleanImplied](/web/20190327225434/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_Node](/web/20190327225434/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Node.md) |
| First written/read in: | ChemDraw 4.0 |
| Required? | No |

**Description:**

If present, signifies that the reaction change of an atom must be as specified.

The value stored in this property corresponds exactly to the Exact Change flag in ISIS.

**If this property is absent:**

The reaction change is treated as unspecified.
