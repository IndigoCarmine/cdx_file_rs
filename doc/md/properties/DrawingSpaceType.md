## DrawingSpaceType Property

| CDXML Name: | DrawingSpace |
| --- | --- |
| CDX Constant Name: | kCDXProp_DrawingSpaceType |
| CDX Constant Value: | 0x0811 |
| Data Size: | [INT8](/web/20160912170307/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Page](/web/20160912170307/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Page.md) |
| First written/read in: | ChemDraw 6.0 |
| Required? | No |

**Description:**

The type of drawing space used for this document.

This is an enumerated property. Acceptable values are shown in the following list:

| Value | CDXML Name | Description |
| --- | --- | --- |
| 0 | Pages | Pages |
| 1 | Poster | Poster |

**If this property is absent:**

The drawing space is measured in Pages.
