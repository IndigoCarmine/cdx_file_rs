CDX Format Specification: NamedAlternativeGroup_GroupFrame Property
## NamedAlternativeGroup_GroupFrame Property

| CDXML Name: | GroupFrame |
| --- | --- |
| CDX Constant Name: | kCDXProp_NamedAlternativeGroup_GroupFrame |
| CDX Constant Value: | 0x0B01 |
| Data Size: | [CDXRectangle](/web/20100103054608/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |
| Property of objects: | [kCDXObj_NamedAlternativeGroup](/web/20100103054608/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/NamedAltGroup.md) |
| First written/read in: | ChemDraw 4.0 |
| Required? | Until ChemDraw 6.0 |

**Description:**  

The bounding box of the lower portion of the Named Alternative Group, containing the definition of the group.

**If this property is absent:**  

The bounds are calculated appropriately based on the size of the contents of the Named Alternative Group.
