## HeightPages Property

| CDXML Name: | HeightPages |
| --- | --- |
| CDX Constant Name: | kCDXProp_HeightPages |
| CDX Constant Value: | 0x0810 |
| Data Size: | [INT16](/web/20160912060746/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Page](/web/20160912060746/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Page.md) |
| First written/read in: | ChemDraw 6.0 |
| Required? | No |

**Description:**

The height of the document in pages.

This property is meaningful only for documents with a [DrawingSpaceType](DrawingSpaceType.md) of type Pages.

**If this property is absent:**

The document is assumed to be one page tall.
