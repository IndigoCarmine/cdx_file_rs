CDX Format Specification: ReactionStep_Arrows Property
## ReactionStep_Arrows Property

| CDXML Name: | ReactionStepArrows |
| --- | --- |
| CDX Constant Name: | kCDXProp_ReactionStep_Arrows |
| CDX Constant Value: | 0x0C04 |
| Data Size: | [CDXObjectIDArray](/web/20160913174212/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXObjectID.md) |
| Property of objects: | [kCDXObj_ReactionStep](/web/20160913174212/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/ReactionStep.md) |
| First written/read in: | ChemDraw 6.0 / (not read) |
| Required? | No |

**Description:**  

An ordered list of arrows used to separate components of the Reaction Step.

**If this property is absent:**  

This property is not read by ChemDraw. It is written as a courtesy only. There is no consequence to omitting it.
