CDX Format Specification: TLC_ShowOrigin Property
## TLC_ShowOrigin Property

| CDXML Name: | ShowOrigin |
| --- | --- |
| CDX Constant Name: | kCDXProp_TLC_ShowOrigin |
| CDX Constant Value: | 0x0AA2 |
| Data Size: | [CDXBoolean](/web/20160912170435/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_TLCPlate](/web/20160912170435/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCPlate.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**  

Show the origin line near the base of the TLC Plate if non-zero.

**If this property is absent:**  

The origin line will not be shown
