CDX Format Specification: Spectrum_YLow Property
## Spectrum_YLow Property

| CDXML Name: | YLow |
| --- | --- |
| CDX Constant Name: | kCDXProp_Spectrum_YLow |
| CDX Constant Value: | 0x0A88 |
| Data Size: | [FLOAT64](/web/20160912170237/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Spectrum](/web/20160912170237/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Spectrum.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**  

Y value to be used to offset data when storing XML.

**If this property is absent:**  

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
