## 2DExtent Property

| CDXML Name: | extent |
| --- | --- |
| CDX Constant Name: | kCDXProp_2DExtent |
| CDX Constant Value: | 0x0202 |
| Data Size: | [CDXPoint2D](/web/20160913174038/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |

**Description:**  

The width and height of an object in CDX coordinate units. The precise meaning of this attribute varies depending on the type of object.
