## FontTable Property

| CDXML Name: | fonttable |
| --- | --- |
| CDX Constant Name: | kCDXProp_FontTable |
| CDX Constant Value: | 0x0100 |
| Data Size: | [CDXFontTable](/web/20160911223857/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXFontTable.md) |
| Property of objects: | [kCDXObj_Document](/web/20160911223857/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Document.md) |
| First written/read in: | ChemDraw 4.0 |
| Required? | Required if fonts are used |

**Description:**

A list of fonts used in the document.

This property is used only in CDX files. In CDXML files, a [Font Table](/web/20160911223857/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/FontTable.md) object is saved instead.
