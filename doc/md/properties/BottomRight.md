## BottomRight Property

| CDXML Name: | BottomRight |
| --- | --- |
| CDX Constant Name: | kCDXProp_BottomRight |
| CDX Constant Value: | 0x020B |
| Data Size: | [CDXPoint2D](/web/20151008030414/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |
| Property of objects: | [kCDXObj_TLCPlate](/web/20151008030414/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCPlate.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**

The location of the bottom-right corner of a quadrilateral object, possibly in a rotated or skewed frame.

**If this property is absent:**

The bottom-right is positioned at (0, 0).
