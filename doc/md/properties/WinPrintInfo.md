## WinPrintInfo Property

| CDXML Name: | WinPrintInfo |
| --- | --- |
| CDX Constant Name: | kCDXProp_WinPrintInfo |
| CDX Constant Value: | 0x0801 |
| Data Size: | [Unformatted](/web/20160912173214/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/Unformatted.md) |
| Property of objects: | [kCDXObj_Document](/web/20160912173214/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Document.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**

The Windows DEVMODE structure associated with the CDX document object.

**If this property is absent:**

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
