## ReactionStep_Reactants Property

| CDXML Name: | ReactionStepReactants |
| --- | --- |
| CDX Constant Name: | kCDXProp_ReactionStep_Reactants |
| CDX Constant Value: | 0x0C01 |
| Data Size: | [CDXObjectIDArray](/web/20160912170343/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXObjectID.md) |
| Property of objects: | [kCDXObj_ReactionStep](/web/20160912170343/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/ReactionStep.md) |
| First written/read in: | ChemDraw 6.0 |
| Required? | No |

**Description:**

An ordered list of reactants present in the Reaction Step.

**If this property is absent:**

There are no reactants in this Reaction Step.
