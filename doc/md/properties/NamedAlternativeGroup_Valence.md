CDX Format Specification: NamedAlternativeGroup_Valence Property
## NamedAlternativeGroup_Valence Property

| CDXML Name: | Valence |
| --- | --- |
| CDX Constant Name: | kCDXProp_NamedAlternativeGroup_Valence |
| CDX Constant Value: | 0x0B02 |
| Data Size: | [INT16](/web/20160911222933/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_NamedAlternativeGroup](/web/20160911222933/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/NamedAltGroup.md) |
| First written/read in: | ChemDraw 4.0 / (not read) |
| Required? | No |

**Description:**  

The number of attachment points in each alternative in a named alternative group.

**If this property is absent:**  

This property is not read by ChemDraw. It is written as a courtesy only. There is no consequence to omitting it.
