CDX Format Specification: HeaderPosition Property
## HeaderPosition Property

| CDXML Name: | HeaderPosition |
| --- | --- |
| CDX Constant Name: | kCDXProp_HeaderPosition |
| CDX Constant Value: | 0x0816 |
| Data Size: | [CDXCoordinate](/web/20160912170406/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |
| Property of objects: | [kCDXObj_Page](/web/20160912170406/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Page.md) |
| First written/read in: | ChemDraw 6.0 |
| Required? | No |

**Description:**  

The vertical offset of the header baseline from the top of the page.

**If this property is absent:**  

The header is not offset at all from the top of the page.
