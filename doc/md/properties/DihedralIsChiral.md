## DihedralIsChiral Property

| CDXML Name: | DihedralIsChiral |
| --- | --- |
| CDX Constant Name: | kCDXProp_DihedralIsChiral |
| CDX Constant Value: | 0x0B87 |
| Data Size: | [CDXBooleanImplied](/web/20160911232545/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_Constraint](/web/20160911232545/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Constraint.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**

Signifies whether a dihedral is signed or unsigned.

This property is meaningful only for constraints that define a dihedral angle.

**If this property is absent:**

The dihedral may be of either sign.
