CDX Format Specification: ReactionStep_Products Property
## ReactionStep_Products Property

| CDXML Name: | ReactionStepProducts |
| --- | --- |
| CDX Constant Name: | kCDXProp_ReactionStep_Products |
| CDX Constant Value: | 0x0C02 |
| Data Size: | [CDXObjectIDArray](/web/20160911233217/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXObjectID.md) |
| Property of objects: | [kCDXObj_ReactionStep](/web/20160911233217/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/ReactionStep.md) |
| First written/read in: | ChemDraw 6.0 |
| Required? | No |

**Description:**  

An order list of products present in the Reaction Step.

**If this property is absent:**  

There are no products in this Reaction Step.
