CDX Format Specification: 3DTail Property
## 3DTail Property

| CDXML Name: | Tail3D |
| --- | --- |
| CDX Constant Name: | kCDXProp_3DTail |
| CDX Constant Value: | 0x0208 |
| Data Size: | [CDXPoint3D](/web/20190327001605/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |
| Property of objects: | [kCDXObj_Graphic](/web/20190327001605/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Graphic.md),[kCDXObj_Arrow](/web/20190327001605/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Arrow.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**  

The 3D location (in the order of X-, Y-, and Z-locations in right-handed coordinate system) of the tail of an object in CDX coordinate units.

This is currently only used for objects (such as arrows) with distinct heads and tails
