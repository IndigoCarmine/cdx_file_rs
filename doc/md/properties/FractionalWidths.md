CDX Format Specification: FractionalWidths Property
## FractionalWidths Property

| CDXML Name: | FractionalWidths |
| --- | --- |
| CDX Constant Name: | kCDXProp_FractionalWidths |
| CDX Constant Value: | 0x080D |
| Data Size: | [CDXBooleanImplied](/web/20190910145438/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_Document](/web/20190910145438/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Document.md) |
| First written/read in: | ChemDraw 4.0 |
| Required? | No |

**Description:**  

Signifies whether to use fractional width information when drawing text.

This is useful only on Macintosh computers.

**If this property is absent:**  

Fractional widths are not used
