## TLC_ShowSolventFront Property

| CDXML Name: | ShowSolventFront |
| --- | --- |
| CDX Constant Name: | kCDXProp_TLC_ShowSolventFront |
| CDX Constant Value: | 0x0AA3 |
| Data Size: | [CDXBoolean](/web/20160912170206/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_TLCPlate](/web/20160912170206/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCPlate.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**

Show the solvent front line near the top of the TLC Plate if non-zero.

**If this property is absent:**

The solvent front will not be shown.
