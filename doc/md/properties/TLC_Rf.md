## TLC_Rf Property

| CDXML Name: | Rf |
| --- | --- |
| CDX Constant Name: | kCDXProp_TLC_Rf |
| CDX Constant Value: | 0x0AB0 |
| Data Size: | [FLOAT64](/web/20100103055113/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_TLCSpot](/web/20100103055113/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCSpot.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**

The Retention Factor (Rf) of an individual spot.

The Retention Factor should be a decimal value between zero and one. Values less than zero or greater than one have no meaning.

**If this property is absent:**

The Rf value will be assigned to a default value, possibly specified by the user.
