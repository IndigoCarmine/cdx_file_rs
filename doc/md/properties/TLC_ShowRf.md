## TLC_ShowRf Property

| CDXML Name: | ShowRf |
| --- | --- |
| CDX Constant Name: | kCDXProp_TLC_ShowRf |
| CDX Constant Value: | 0x0AB2 |
| Data Size: | [CDXBoolean](/web/20160911225835/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_TLCSpot](/web/20160911225835/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCSpot.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**

Show the spot's Retention Fraction (Rf) value if non-zero.

**If this property is absent:**

The Rf value of the spot will not be shown.
