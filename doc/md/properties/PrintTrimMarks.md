CDX Format Specification: PrintTrimMarks Property
## PrintTrimMarks Property

| CDXML Name: | PrintTrimMarks |
| --- | --- |
| CDX Constant Name: | kCDXProp_PrintTrimMarks |
| CDX Constant Value: | 0x0819 |
| Data Size: | [CDXBooleanImplied](/web/20160912001034/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_Page](/web/20160912001034/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Page.md) |
| First written/read in: | ChemDraw 6.0 |
| Required? | No |

**Description:**  

If present, trim marks are to printed in the margins.

**If this property is absent:**  

Trim marks are not printed.
