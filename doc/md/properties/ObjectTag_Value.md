CDX Format Specification: ObjectTag_Value Property
## ObjectTag_Value Property

| CDXML Name: | Value |
| --- | --- |
| CDX Constant Name: | kCDXProp_ObjectTag_Value |
| CDX Constant Value: | 0x0D05 |
| Data Size: | varies |
| Property of objects: | [kCDXObj_ObjectTag](/web/20190326232119/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/ObjectTag.md) |
| First written/read in: | ChemDraw 6.0 |
| Required? | No |

**Description:**  

The value is a INT32, FLOAT64 or unformatted string depending on the value of ObjectTag_Type.

**If this property is absent:**  

The value will be treated as zero.
