CDX Format Specification: BottomLeft Property
## BottomLeft Property

| CDXML Name: | BottomLeft |
| --- | --- |
| CDX Constant Name: | kCDXProp_BottomLeft |
| CDX Constant Value: | 0x020C |
| Data Size: | [CDXPoint2D](/web/20160913174015/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |
| Property of objects: | [kCDXObj_TLCPlate](/web/20160913174015/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCPlate.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**  

The location of the bottom-left corner of a quadrilateral object, possibly in a rotated or skewed frame.

**If this property is absent:**  

The bottom-left is positioned at (0, 0).
