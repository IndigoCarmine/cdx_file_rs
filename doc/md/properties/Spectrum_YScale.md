CDX Format Specification: Spectrum_YScale Property
## Spectrum_YScale Property

| CDXML Name: | YScale |
| --- | --- |
| CDX Constant Name: | kCDXProp_Spectrum_YScale |
| CDX Constant Value: | 0x0A89 |
| Data Size: | [FLOAT64](/web/20160912170428/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Spectrum](/web/20160912170428/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Spectrum.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**  

Y scaling used to scale data when storing XML.

**If this property is absent:**  

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
