## Mole_Weight Property

| CDXML Name: | Weight |
| --- | --- |
| CDX Constant Name: | kCDXProp_Mole_Weight |
| CDX Constant Value: | 0x0504 |
| Data Size: | [FLOAT64](/web/20160913174311/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Fragment](/web/20160913174311/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Fragment.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**

The average molecular weight of a molecule object.

**If this property is absent:**

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
