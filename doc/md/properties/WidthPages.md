CDX Format Specification: WidthPages Property
## WidthPages Property

| CDXML Name: | WidthPages |
| --- | --- |
| CDX Constant Name: | kCDXProp_WidthPages |
| CDX Constant Value: | 0x080F |
| Data Size: | [INT16](/web/20160912002025/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Page](/web/20160912002025/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Page.md) |
| First written/read in: | ChemDraw 6.0 |
| Required? | No |

**Description:**  

The width of the document in pages.

This property is meaningful only for documents with a [DrawingSpaceType](DrawingSpaceType.md) of type Pages.

**If this property is absent:**  

The document is assumed to be one page wide.
