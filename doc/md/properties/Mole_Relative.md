## Mole_Relative Property

| CDXML Name: | Relative |
| --- | --- |
| CDX Constant Name: | kCDXProp_Mole_Relative |
| CDX Constant Value: | 0x0502 |
| Data Size: | [CDXBoolean](/web/20160912170246/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_Fragment](/web/20160912170246/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Fragment.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**

Indicates that the molecule has known relative stereochemistry, but unknown absolute configuration.

**If this property is absent:**

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
