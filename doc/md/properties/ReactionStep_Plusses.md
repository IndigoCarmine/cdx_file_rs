## ReactionStep_Plusses Property

| CDXML Name: | ReactionStepPlusses |
| --- | --- |
| CDX Constant Name: | kCDXProp_ReactionStep_Plusses |
| CDX Constant Value: | 0x0C03 |
| Data Size: | [CDXObjectIDArray](/web/20160912060823/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXObjectID.md) |
| Property of objects: | [kCDXObj_ReactionStep](/web/20160912060823/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/ReactionStep.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**

An ordered list of pluses used to separate components of the Reaction Step.

**If this property is absent:**

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
