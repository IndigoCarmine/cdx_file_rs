## TLC_ShowBorders Property

| CDXML Name: | ShowBorders |
| --- | --- |
| CDX Constant Name: | kCDXProp_TLC_ShowBorders |
| CDX Constant Value: | 0x0AA4 |
| Data Size: | [CDXBoolean](/web/20160912014500/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_TLCPlate](/web/20160912014500/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCPlate.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**

Show borders around the edges of the TLC Plate if non-zero.

**If this property is absent:**

The borders will not be shown.
