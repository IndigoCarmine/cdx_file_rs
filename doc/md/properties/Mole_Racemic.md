CDX Format Specification: Mole_Racemic Property
## Mole_Racemic Property

| CDXML Name: | Racemic |
| --- | --- |
| CDX Constant Name: | kCDXProp_Mole_Racemic |
| CDX Constant Value: | 0x0500 |
| Data Size: | [CDXBoolean](/web/20190819212259/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_Fragment](/web/20190819212259/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Fragment.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**  

Indicates that the molecule is a racemic mixture.

**If this property is absent:**  

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
