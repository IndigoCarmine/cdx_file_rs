## Window_IsZoomed Property

| CDXML Name: | WindowIsZoomed |
| --- | --- |
| CDX Constant Name: | kCDXProp_Window_IsZoomed |
| CDX Constant Value: | 0x0900 |
| Data Size: | [CDXBooleanImplied](/web/20160913174157/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXBoolean.md) |
| Property of objects: | [kCDXObj_Document](/web/20160913174157/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Document.md) |
| First written/read in: | ChemDraw 4.0 |
| Required? | No |

**Description:**  

Signifies whether the main viewing window is zoomed (maximized).

**If this property is absent:**  

The window is not zoomed (maximized)
