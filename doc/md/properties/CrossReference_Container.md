## CrossReference_Container Property

| CDXML Name: | CrossReferenceContainer |
| --- | --- |
| CDX Constant Name: | kCDXProp_CrossReference_Container |
| CDX Constant Value: | 0x0F00 |
| Data Size: | [CDXString](/web/20160912002116/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXString.md) |
| Property of objects: | [kCDXObj_CrossReference](/web/20160912002116/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/CrossReference.md) |
| First written/read in: | ChemDraw 7.0 |
| Required? | No |

**Description:**

An external object containing (as an embedded object) the document containing the Sequence object being referenced.

This property is provided for future compatibility and is not currently used in any case by ChemDraw.

**If this property is absent:**

This is the empty string.
