CDX Format Specification: CreationDate Property
## CreationDate Property

| CDXML Name: | CreationDate |
| --- | --- |
| CDX Constant Name: | kCDXProp_CreationDate |
| CDX Constant Value: | 0x0002 |
| Data Size: | [CDXDate](/web/20160912170424/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/DateAndTime.md) |
| Property of objects: | [kCDXObj_Document](/web/20160912170424/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Document.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**  

The time of object creation.

**If this property is absent:**  

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
