CDX Format Specification: Spectrum_XSpacing Property
## Spectrum_XSpacing Property

| CDXML Name: | XSpacing |
| --- | --- |
| CDX Constant Name: | kCDXProp_Spectrum_XSpacing |
| CDX Constant Value: | 0x0A80 |
| Data Size: | [FLOAT64](/web/20160911225941/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXNumeric.md) |
| Property of objects: | [kCDXObj_Spectrum](/web/20160911225941/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Spectrum.md) |
| First written/read in: | ChemDraw 5.0 |
| Required? | Required for spectra |

**Description:**  

The spacing in logical units (ppm, Hz, wavenumbers) between points along the X-axis of an evenly-spaced grid.
