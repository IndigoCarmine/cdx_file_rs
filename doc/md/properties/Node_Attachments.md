## Node_Attachments Property

| CDXML Name: | Attachments |
| --- | --- |
| CDX Constant Name: | kCDXProp_Node_Attachments |
| CDX Constant Value: | 0x0432 |
| Data Size: | [CDXObjectIDArrayWithCounts](/web/20190327221555/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXObjectID.md) |
| Property of objects: | [kCDXObj_Node](/web/20190327221555/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Node.md) |
| First written/read in: | ChemDraw 4.0 |
| Required? | Required for multi- and variable attached nodes |

**Description:**

For multicenter attachment nodes or variable attachment nodes, a list of IDs of the nodes which are multiply or variably attached to this node.
