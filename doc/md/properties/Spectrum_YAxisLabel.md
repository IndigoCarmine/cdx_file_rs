CDX Format Specification: Spectrum_YAxisLabel Property
## Spectrum_YAxisLabel Property

| CDXML Name: | YAxisLabel |
| --- | --- |
| CDX Constant Name: | kCDXProp_Spectrum_YAxisLabel |
| CDX Constant Value: | 0x0A85 |
| Data Size: | [CDXString](/web/20160912060811/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXString.md) |
| Property of objects: | [kCDXObj_Spectrum](/web/20160912060811/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Spectrum.md) |
| First written/read in: | ChemDraw 5.0 / (not read) |
| Required? | No |

**Description:**  

A label for the Y-axis.

**If this property is absent:**  

This property is not read by ChemDraw. It is written as a courtesy only. There is no consequence to omitting it.
