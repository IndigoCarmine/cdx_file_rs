## TLC_Tail Property

| CDXML Name: | Tail |
| --- | --- |
| CDX Constant Name: | kCDXProp_TLC_Tail |
| CDX Constant Value: | 0x0AB1 |
| Data Size: | [CDXCoordinate](/web/20160913174054/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |
| Property of objects: | [kCDXObj_TLCSpot](/web/20160913174054/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCSpot.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**

The length of the "tail" of an individual spot.

**If this property is absent:**

The spot will be assumed to have no tail (it will be drawn as an undistorted ellipsoid).
