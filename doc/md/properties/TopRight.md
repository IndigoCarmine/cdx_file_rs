CDX Format Specification: TopRight Property
## TopRight Property

| CDXML Name: | TopRight |
| --- | --- |
| CDX Constant Name: | kCDXProp_TopRight |
| CDX Constant Value: | 0x020A |
| Data Size: | [CDXPoint2D](/web/20160911235002/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |
| Property of objects: | [kCDXObj_TLCPlate](/web/20160911235002/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCPlate.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**  

The location of the top-right corner of a quadrilateral object, possibly in a rotated or skewed frame.

**If this property is absent:**  

The top-right is positioned at (0, 0).
