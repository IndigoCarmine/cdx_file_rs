CDX Format Specification: TopLeft Property
## TopLeft Property

| CDXML Name: | TopLeft |
| --- | --- |
| CDX Constant Name: | kCDXProp_TopLeft |
| CDX Constant Value: | 0x0209 |
| Data Size: | [CDXPoint2D](/web/20160912170310/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXCoordinates.md) |
| Property of objects: | [kCDXObj_TLCPlate](/web/20160912170310/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/TLCPlate.md) |
| First written/read in: | ChemDraw 8.0 |
| Required? | No |

**Description:**  

The location of the top-left corner of a quadrilateral object, possibly in a rotated or skewed frame.

**If this property is absent:**  

The top-left is positioned at (0, 0).
