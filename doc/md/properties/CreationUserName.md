## CreationUserName Property

| CDXML Name: | CreationUserName |
| --- | --- |
| CDX Constant Name: | kCDXProp_CreationUserName |
| CDX Constant Value: | 0x0001 |
| Data Size: | [CDXString](/web/20160912170221/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXString.md) |
| Property of objects: | [kCDXObj_Document](/web/20160912170221/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Document.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**

The name of the creator (program user's name) of the document.

**If this property is absent:**

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
