CDX Format Specification: Mole_Formula Property
## Mole_Formula Property

| CDXML Name: | Formula |
| --- | --- |
| CDX Constant Name: | kCDXProp_Mole_Formula |
| CDX Constant Value: | 0x0503 |
| Data Size: | [CDXFormula](/web/20190819212620/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/DataType/CDXFormula.md) |
| Property of objects: | [kCDXObj_Fragment](/web/20190819212620/http://www.cambridgesoft.com/services/documentation/sdk/chemdraw/cdx/Fragment.md) |
| First written/read in: | (not written/read) |
| Required? | No |

**Description:**  

The molecular formula representation of a molecule object.

**If this property is absent:**  

This property is not read (or written) by ChemDraw, but is defined for future compatibility. There is no consequence to omitting it.
