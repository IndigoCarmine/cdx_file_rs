CDX Format Specification: CDX Curve Points 3D Data Type
## CDX Curve Points 3D Data Type

This data type consists of a series of [CDXPoint3D](CDXCoordinates.md) values.

**In CDX files**, this data type is prefixed by an additional [UINT16](CDXNumeric.md) value indicating the total number of CDXPoints to follow.

**Examples:**

| CDX: | 02 00 01 00 00 00 02 00 00 00 03 00 00 00 04 00 00 00 05 00 00 00 06 00 00 00 |
| --- | --- |
| CDXML: | "1 2 3 4 5 6" |
